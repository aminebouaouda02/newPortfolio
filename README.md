# My Portfolio

This is a React project scaffolded using Vite. This portfolio showcases my work and skills in Big Data and IoT.

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/aminebouaouda02/newPortfolio.git
   cd newPortfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## Development

To start the development server, run:
```bash
npm run dev
```

## Build

To create a production build, run:
```bash
npm run build
```

## Preview

To preview the production build, run:
```bash
npm run preview
```

## Deploying to GitHub Pages

To deploy the app to GitHub Pages, run:
```bash
npm run deploy
```
